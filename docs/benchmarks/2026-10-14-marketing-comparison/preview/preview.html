Test settings and what these comparisons cover

AMD EPYC 9655P 96-Core Processor. One target at a time; separate generator. Each S3 server uses the same resource ceilings and client workflows. Filesystem and memory backends are compared separately. Bars use a linear scale from zero; ranges describe observed samples.

These peers expose S3-shaped blob storage. The workloads exercise bucket creation, PUT, GET and DELETE; they do not establish full S3 feature parity. Durability guarantees differ: Stow filesystem publishes with rename and fsync; S3Proxy’s filesystem adapter differs; RustFS uses one drive with strict durability.

These are exploratory development measurements. Image downloads, deployments, browser startup, cold OS caches, real scanners, flagged-file promotion, replication and failover are unmeasured. Some target runs reach the CPU ceiling; the fixed generator and concurrency can also constrain rates.
