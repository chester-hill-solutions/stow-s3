# Release notes

The current native and Go release is [v0.4.2](v0.4.2.md), with qualified
Linux and macOS binaries on x64 and ARM64. [v0.4.3](v0.4.3.md) is prepared in
this tree; its tag and binaries follow the authorized release step. The npm
packages remain at **0.3.7**; automated npm and PyPI publication remain
disabled.

The Python client is not yet published to PyPI. See [getting started](../guides/getting-started.md)
for installation and the [npm publication record](../development/npm-publishing.md)
for verification and remaining publishing automation work.
