# Stow v0.3.1

This patch release adds reproducible performance measurement tools and publishes
carefully scoped benchmark results. The runtime API and storage formats are
unchanged from v0.3.0.

## Distribution

Native downloads are available for Linux and macOS on x86_64 and ARM64. Verify
each archive against `SHA256SUMS.txt` from this release. npm and PyPI publication
remain deferred; build those clients from a source checkout.

## Changes

- Add a performance runner for memory and filesystem storage, the S3 endpoint,
  throughput and latency, resource sampling, and a simulated quarantine flow.
- Add an embedded Go benchmark for PUT, verified GET and quarantine workflows.
- Add smoke and longer qualification profiles with explicit limits, recovery
  checks, source identity and measurement boundaries.
- Publish exploratory benchmark data and interactive comparison charts on the
  documentation site. Results describe their tested workloads and host limits;
  they do not establish broad performance superiority or sustained production
  capacity.

## Compatibility

This release does not change the public API or on-disk object format. The
filesystem upgrade restriction from v0.3.0 still applies: old Stow versions
cannot read version-2 records written by newer releases. Preserve a backup if
you need to downgrade.
