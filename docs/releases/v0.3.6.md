# Stow v0.3.6

This patch release cleans up the repository and benchmark tooling, fixes source
packaging, and updates the documentation and website. Storage behavior and
public APIs are unchanged from v0.3.5.

## Distribution

Native GitHub downloads cover Linux and macOS on x86_64 and ARM64. Verify each
archive against `SHA256SUMS.txt`, then run `stow-s3 --version` to confirm 0.3.6.
The Go module is also available at the v0.3.6 tag.

The five public npm packages remain at **0.3.5**:

```sh
npm install @chester-hill-solutions/stow-s3@0.3.5
```

This release does not publish npm packages or PyPI wheels. Automated registry
publication and trusted publishing remain disabled. Source package versions
are aligned to 0.3.6 for local builds and packed-consumer qualification; that
does not claim that version is available from a registry. The unpublished
optional native carriers have no registry integrity in the source lockfile;
development tests build and select the source binary.

## Cleanup and fixes

- Use one private-file exclusion policy for minimal and full benchmark source
  packages, including `.env` variants, credentials, caches and generated outputs.
  Recursive copies can no longer reintroduce paths omitted from the file inventory.
- Validate image modes and their modifiers before creating output. Refuse unknown
  or conflicting options, honor working-tree deletions, exclude stale source
  receipts, and report an empty dirty-file list for a clean checkout.
- Add ten packaging regression tests and run the complete benchmark controls
  suite in required CI with its locked prerequisites installed.
- Group eleven specialized Docker recipes under `benchmark/docker/`, preserving
  the default image path and recipe contents.
- Retire the obsolete multiplayer prototype and its three Make commands. Live
  collaboration belongs to GangCode; historical references retain the exact
  original Git snapshot.
- Remove generated historical artifacts from the current tree while retaining
  recovery references in Git. Organize guides, contracts, design documents and
  development material into folders and repair their links.
- Refresh installation guidance, repository presentation and website use cases.
  The CI use case explains image pulls, service setup, readiness and teardown;
  it makes no claim of a measured CI startup speedup.

## Compatibility and qualification

No public API or storage-format migration is introduced. Existing record-v2 and
outbox schema-4 downgrade restrictions remain. Go stays pinned to 1.25.6 and
the TypeScript client continues to support Node 20 and newer.

The release pipeline requires tests, standards, reproducible generated output,
four native builds and wheels, and packed consumers on all four supported native
platforms before publishing GitHub downloads. Windows native downloads remain
unsupported. This release makes no executed-live-provider or general crash-recovery
claim, and does not extend the first-npm-release provider waiver beyond 0.3.5.
