# Stow v0.3.7

This patch release makes storage and browser resource lifecycles explicit,
fixes shutdown and cancellation races, and updates the embedded MCP browser's
validation dependencies.

## Distribution

Native GitHub downloads cover Linux and macOS on x86_64 and ARM64. Verify each
archive against `SHA256SUMS.txt`, then run `stow-s3 --version` to confirm 0.3.7.
The Go module is also available at the v0.3.7 tag.

The five public npm packages remain at **0.3.5**:

```sh
npm install @chester-hill-solutions/stow-s3@0.3.5
```

This release does not publish npm packages or PyPI wheels. Automated registry
publication and trusted publishing remain disabled. Source package versions
are aligned to 0.3.7 for local builds and packed-consumer qualification; that
does not claim that version is available from a registry. The unpublished
optional native carriers have no registry integrity in the source lockfile;
development tests build and select the source binary. TypeScript source changes
in this release are available from the source checkout, not the 0.3.5 npm package.

## Fixes and safeguards

- Model workspace and HTTP server shutdown with explicit states. Keep storage
  available to active HTTP handlers when shutdown is interrupted, and preserve
  the original startup readiness signal after a rejected duplicate start.
- Model asynchronous readers and IndexedDB adapters with explicit states. Retry
  failed reader cleanup, coordinate simultaneous database opens, and close or
  abort database work that completes after cancellation or a rejected open.
- Centralize outbox publication, retry and terminal transitions while keeping
  lease ownership and attempt history separate. Fence stale worker updates,
  stop cancelled propagation, and schedule retries with bounded equal-jitter
  exponential backoff.
- Reject new implicit lifecycle flag combinations with an AST-based standards
  check. Guard the compatibility baseline against additions and stale entries.
- Update Zod to 4.6.6 throughout the embedded MCP browser dependency tree to
  address [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
  Refresh compatible transitive dependencies with security fixes and regenerate
  the browser asset embedded in native binaries.

## Compatibility and qualification

No public API or storage-format migration is introduced. Existing outbox entry
fields and persisted representations remain compatible. Existing record-v2 and
outbox schema-4 downgrade restrictions remain. Go stays pinned to 1.25.6 and
the TypeScript client continues to support Node 20 and newer.

The release pipeline requires tests, standards, reproducible generated output,
four native builds and wheels, and packed consumers on all four supported native
platforms before publishing GitHub downloads. Windows native downloads remain
unsupported. This release makes no executed-live-provider, 1 GiB browser workload
or general crash-recovery claim, and does not extend the first-npm-release
provider waiver beyond 0.3.5.
