# Stow v0.4.0 candidate (unreleased)

> This is a release candidate record, not a release announcement. Version 0.4.0
> is not published to npm or PyPI, and no GitHub release or native download is
> available yet. Keep using the public v0.3.7 instructions until a release is
> announced.

## Candidate changes

- Add opt-in MCP workspace file resources for live directories, paged directory
  listings and bounded file reads.
- Add opt-in resources for a host-selected saved checkpoint, including bounded
  directory and byte-range reads.
- Add opt-in native workspace editing tools for reading a file before a save,
  submitting an idempotent save request and resolving its receipt.
- Add durable file-save recovery records and checkpoint barriers that refuse
  capture or cleanup while a save is unresolved.
- Add workspace browser support and documentation for the opt-in profiles.

The existing object-server profile and default MCP startup remain unchanged.
These features do not claim to sandbox other host processes or control their
network access.

## Distribution and qualification

The candidate version is synchronized across the Go binary, TypeScript package,
platform carrier manifests and Python package metadata. The npm lock records the
new optional carrier versions without copying the 0.3.7 tarball URLs or
integrities; the 0.4.0 carriers have not been published.

Exact-source release tests, reproducible generated output, four native builds,
platform wheels and packed consumer checks must pass before distribution.
Revision-bound qualification results and artifact identities are tracked in
[release candidate PR #139](https://github.com/chester-hill-solutions/stow-s3/pull/139),
including installed-carrier MCP reads, saves and checkpoint reads on each native
platform. Named external consumer hosts and model-provider behavior require
separate evidence; a platform smoke does not establish those claims.

Automated npm publication, npm trusted publishing and PyPI publication remain
disabled. This candidate makes no claim of public package availability, Windows
workspace-feature support or cross-host adoption qualification.
