# Stow v0.4.2

This patch updates AWS SDK dependencies and adds download-recovery qualification.
It introduces no public API or storage-format migration.

## Changes since v0.4.1

- Update the Go AWS SDK, credentials, S3 client and Smithy dependencies.
  Keep the benchmark module and checksums aligned.
- Update the JavaScript S3 request presigner and compatible Smithy dependencies.
  Retain signing and sensitive-field logging regression coverage.
- Update ESLint and typescript-eslint without disabling rules or changing ratchet baselines.
- Add download-recovery conformance and a bounded transfer-cost probe.
  Dated workload evidence retains its source identities and qualification limits.
- Record published-binary interrupted Mac-to-Linux continuation evidence.
  This evidence does not establish general crash recovery or add a transfer SDK.

## npm status

The v0.4.2 native binaries include the workspace features introduced in
[v0.4.0](v0.4.0.md) and the policy-mode correction in [v0.4.1](v0.4.1.md):
opt-in MCP workspace resources, managed file saves and checkpoint reads.
Managed saves require host-quiesced writers and retained request keys.

**npm remains at 0.3.7.** The 0.4.2 npm publication has not happened, so the
installable npm version is:

```sh
npm install @chester-hill-solutions/stow-s3@0.3.7
```

For the 0.4.2 native profiles, download the GitHub release binaries. The npm
carrier for 0.4.2 is not available until the interactive publication runs.

## Compatibility and limits

Existing filesystem record-v2 and outbox schema-4 downgrade restrictions continue to apply.
Go remains pinned to 1.25.6 and the core TypeScript compiler remains at 5.9.3.
The held Go 1.26 memory-contract and core TypeScript 7 migrations are excluded.
Existing dependency audit findings remain unresolved; this release is not a clean security audit.

Local qualification and packed consumers do not establish live-provider compatibility.
No executed AWS S3, Cloudflare R2 or custom-provider compatibility claim is made.
Existing workspace trust, retention, plaintext and writer-quiescence limits remain.
