# Documentation routes validate without generated website output

Baseline: `8e0fc34`, following the separately reviewed object-quota correction.

The six reported links in `site/agent.md` name valid routes in `site/docs.mjs`.
Each route's Markdown source exists. The checker nevertheless reported missing
files when `site/.build` was absent, so a clean checkout failed its documentation
check before building the website. Building the site merely masked the defect.

The correction reuses the existing site route manifest. For an absolute website
link, the checker resolves a static asset first, then a declared documentation
route's source, retaining the existing built-output fallback for other paths.
This requires no site build or installed website dependencies. It also refuses a
missing source even if an old generated page remains on disk. There is no new
route list, dependency, public API, website content change or storage change.

Before changing the checker, two new regression tests failed: a declared route
with a valid source failed in a clean checkout, and stale output hid a missing
source. The third new test verifies static assets still work. Typos, missing
assets, machine-specific paths, repository escapes and ordinary document links
retain their existing checks. The six affected links now pass with no
`site/.build` directory present.

Evidence: [before failures](2026-10-15-doc-links/before-tests.log),
[the original six reports](2026-10-15-doc-links/before-links.log),
[passing regression tests](2026-10-15-doc-links/after-tests.log), and
[passing repository link check](2026-10-15-doc-links/after-links.log).

Validation includes all six checker tests, the full script suite, all seven
website tests (including a full temporary build and public navigation checks),
the documentation-command checker, file-size ratchet and diff checks. The first
broad script run lacked the worktree's TypeScript dependency; rerunning with the
already installed matching package dependencies passes. Temporary dependency
links were removed. See [script results](2026-10-15-doc-links/scripts-tests.log)
and [website results](2026-10-15-doc-links/site-tests.log).

The quality tool performs one small manifest search per absolute website link;
no application runtime cost or storage compatibility change is introduced.
Known documentation routes now require their source file, which intentionally
prevents stale builds from making a broken source tree appear valid. Existing
anchor handling is unchanged. No additional storage defect was demonstrated in
this change; further investigation remains separate from these two corrections.
