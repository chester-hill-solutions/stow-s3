STOW

Prepare, work, checkpoint,
diff, hand off.

prepare
⟶
work
⟶
checkpoint
⟶
diff
⟶
export

Every checkpoint carries a path, a size, a mode and a SHA-256 per file. The diff is computed from those hashes, so it says what the agent actually changed rather than what you hoped it changed.

Nothing is retained implicitly github.com/chester-hill-solutions/stow-s3
